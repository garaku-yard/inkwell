# Log

What was found or done at a point in time: a trial, an audit, a set of
findings, a superseded plan. Each entry was true as of its date and is not in
force; a finding that leads to a decision is followed by an ADR in
`../decisions/` that cites it.

- Name entries `YYYY-MM-DD-<slug>.md`. `orbit template check` fails on any
  other name in this folder.
- Never edit an entry after the day it was written. Correct it with a new one.
- Nothing here is pruned, and nothing here is loaded into an agent's session.
