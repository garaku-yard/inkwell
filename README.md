# Screenwriting App

A modern, web-based screenwriting application built with Next.js, featuring
proper screenplay formatting, scene navigation, and a clean, distraction-free
writing interface.

## Features

- ✍️ **Proper Screenplay Formatting** - Industry-standard formatting with
monospaced fonts
- 🎬 **Element-Based Writing** - Quick access to scene headings, action,
character, dialogue, and more
- 📋 **Scene Navigation** - Organized sidebar for managing and navigating
scenes
- 🎨 **Clean Interface** - Distraction-free writing environment
- 📱 **Responsive Design** - Works on desktop, tablet, and mobile devices
- 🔧 **Format Toolbar** - Visual icons for all screenplay elements

## Prerequisites

Before running this application, make sure you have the following installed on
your system:

### Required Software

- **Node.js** (version 18.18 or later)
  - Download from [nodejs.org](https://nodejs.org/)
  - Verify installation: `node --version`

- **npm** (comes with Node.js) or **yarn** or **pnpm**
  - Verify npm: `npm --version`
  - Or install yarn: `npm install -g yarn`
  - Or install pnpm: `npm install -g pnpm`

## Running the Application

### Development Mode

1. **Navigate to your project directory:** ```bash cd client```

2. **Start the development server:** ```bash npm run dev```

3. **Open your browser** and navigate to: ``` http://localhost:3000 ```

### Production Build

To create a production build:

```bash npm run build npm start``
