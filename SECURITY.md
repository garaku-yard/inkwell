# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch. Older
releases may not receive backports while Inkwell remains pre-1.0.

## Reporting a vulnerability

Please use GitHub's **Report a vulnerability** form in the repository's
Security tab. This creates a private report that can be discussed and fixed
without exposing users before a patch is available.

Do not open a public issue for a suspected vulnerability and do not include
credentials, private documents, or other sensitive data in public reports.

Include the affected version, platform, reproduction steps, impact, and any
known workaround. We will acknowledge a report as soon as practical and keep
you informed while it is investigated.
